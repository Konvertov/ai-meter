**AI Meter** is a free app for macOS and Windows. It lives in the menu bar or the tray, finds the AI tools you already use (Claude Code, Codex, Cursor, GitHub Copilot, Gemini and more) and shows their session, weekly and monthly limits with a countdown to the next reset.

- macOS 11 or newer: download the `.dmg`, drag AI Meter to Applications. The first time, right-click the app and choose Open.
- Windows 10 or 11: download the `-setup.exe` and run it. If Windows shows "Windows protected your PC", click More info, then Run anyway.

New versions install themselves. No account, no server, no statistics: everything stays on your computer.

**AI Meter** — бесплатное приложение для macOS и Windows. Живёт в строке меню или в трее, само находит нейросети, которыми вы пользуетесь (Claude Code, Codex, Cursor, GitHub Copilot, Gemini и другие), и показывает лимиты на сессию, неделю и месяц с отсчётом до сброса.

- macOS 11 и новее: скачайте `.dmg` и перетащите AI Meter в «Программы». В первый раз нажмите на приложение правой кнопкой и выберите «Открыть».
- Windows 10 и 11: скачайте `-setup.exe` и запустите. Если появится «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».

Новые версии ставятся сами. Без аккаунта, без сервера, без сбора статистики: всё остаётся на вашем компьютере.
